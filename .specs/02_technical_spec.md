# 02. Especificación Técnica y Arquitectura — ChangoCheck

## 1. Arquitectura del Sistema
* **Tipo:** Progressive Web App (PWA) Serverless basada en arquitectura Jamstack.
* **Frontend:** HTML5 semántico, CSS3 moderno (Mobile First), JavaScript vainilla estructurado en ES Modules (`app.js`).
* **Librería de Escaneo:** `html5-qrcode` integrada como script externo o CDN, con acceso a la cámara trasera (`facingMode: "environment"`).
* **Backend y Persistencia:** Supabase (PostgreSQL 15+ con motor Realtime habilitado vía WebSockets).
* **Caché y Shell:** Service Worker (`sw.js`) con estrategia Cache-First para recursos estáticos del app shell y Network-Only para peticiones a la API de Supabase.
* **Requisito de Contexto Seguro:** Despliegue estricto bajo HTTPS (vía GitHub Pages o Cloudflare Pages) para habilitar permisos de cámara (`navigator.mediaDevices.getUserMedia`) y registro de Service Worker.

## 2. Esquema Relacional de Base de Datos (Supabase DDL)

```sql
create table if not exists public.precios (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  codigo_barra varchar(64),
  comercio varchar(80) not null,
  producto varchar(150) not null,
  precio_total numeric(12,2) not null check (precio_total > 0),
  cantidad numeric(8,3) not null default 1.0 check (cantidad > 0),
  unidad varchar(10) not null check (unidad in ('kg', 'g', 'l', 'ml', 'un')),
  precio_unitario numeric(12,2) not null check (precio_unitario > 0)
);

-- Índices de consulta rápida
create index if not exists idx_precios_codigo_barra on public.precios (codigo_barra);
create index if not exists idx_precios_producto on public.precios (lower(producto));
create index if not exists idx_precios_comercio on public.precios (lower(comercio));
create index if not exists idx_precios_precio_unitario on public.precios (precio_unitario asc);

-- Publicación Realtime
alter publication supabase_realtime add table public.precios;
